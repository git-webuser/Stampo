# Stampo — как работать в этом репозитории

## Тесты

Пока задача в работе, весь набор не гоняется — только сьюты, которые касаются
изменённого кода:

```bash
bash Scripts/run-tests.sh \
  -only-testing:StampoTests/PanelMorphFrameTests \
  -only-testing:StampoTests/PanelRenderTests
```

После `StampoTests/` стоит имя типа сьюта (`@Suite struct …`), а не файла: в
одном файле их бывает несколько. Какие сьюты трогают изменённый тип —
`grep -l ИмяТипа StampoTests/*.swift`. После прогона сверить строку
`Tests reported: N`: число должно соответствовать выбранным сьютам, а не всему
набору.

Весь набор (`bash Scripts/run-tests.sh` без аргументов) запускается один раз —
когда закончена большая задача, перед релизом (`RELEASING.md`, шаг 0). В конце
отдельной правки или PR он не нужен: там тоже прогоняются только затронутые
сьюты, а весь набор CI и так гоняет на каждый пуш.

## Ручная проверка

Сборку для ручной проверки собирает и запускает Claude — пользователя не просят
вводить команды:

```bash
bash Scripts/run-dev.sh            # собрать Debug этого чекаута и запустить именно его
bash Scripts/run-dev.sh --demo     # то же с заполненным демо-архивом
bash Scripts/run-dev.sh --restore  # вернуть копию, которая работала до этого
```

Копий Stampo.app с одним bundle id несколько: своя DerivedData у каждого
worktree, `build/export`, архив. Запуск по имени открывает какую попало, а
старая сборка выглядит точно как неработающий фикс. Скрипт запускает по полному
пути и сверяет с процессами. В сообщении «можно проверять» — строка `Running: …`
из его вывода: путь, ветка, коммит, время сборки. На «не работает» сначала
сверить эту строку, потом чинить код.

## UI-правки

- Новый контрол не собирать, если такой уже есть. «Как у X» — значит взять X.
- Видимые решения пользователя — размеры, глифы, тексты, отступы, номер
  версии — не «исправлять» без вопроса: чаще всего они сделаны намеренно.
- Правку размеров, отступов, хит-зон или анимации приносить с доказательством:
  снимок, замер или раскадровка (скилл `ui-evidence`, хелпер
  `StampoTests/ProbeSupport.swift`). Что замером не проверить — перечислить
  отдельно для ручной проверки.
